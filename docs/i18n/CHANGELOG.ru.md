### Эмуляция
- Новый нативный arm64-движок: Android 5.0–17 и GSI (8–17) работают прямо на телефоне; Android 2.3–4.4 — через QEMU.
- Поддержка 64-битных прошивок; 32-битные программы в них работают через qemu-arm.
- Полная поддержка Android 8, включая GSI.
- zygote и mediaserver падают намного реже (исправления binder, устранена блокировка system_server).
- `/system` доступен гостю только для чтения, предкомпилированный код фреймворка больше не теряется.
- Первая загрузка Dalvik-прошивок быстрее (Galaxy S III: 104 с → 59 с).
- Опция аппаратного 32-битного исполнения (AArch32) без транслятора, при отсутствии — QEMU.
- GLES 1/2/3 через SwiftShader.

### Прошивки и производители
- TouchWiz: `ro.tvout.enable=false`, `ro.SecEDS.enable=false` и патчи binder.
- Прошивки Qualcomm: удаляются `qti_permissions.xml`, `com.qti.dpmframework.xml`, `com.qualcomm.location`, `qcrilmsgtunnel`, `dpmserviceapp`, `DiracAudioControlService`, `DiracManager`.
- Infinix (AOSP / XUI / XOS) и Tecno (AOSP / HiOS) определяются по версии Android.
- Sony: эмуляция светового индикатора.
- Исправления для MIUI, HTC Sense, TouchWiz, Xperia и AOSP. Проверено на Nexus 4, Galaxy Nexus, Galaxy S II/S III, Redmi 1S, Desire HD, One M7, Nexus 5X, Phh 9, AOSP GSI 17.

### Импорт
- Новые форматы: 7z, RAR, `.pac`, yaffs2, rfs, EROFS, `super.img`, APEX, `.tar.gz`.

### Функции
- Интернет работает в большем числе прошивок.
- Исправлен звук; добавлены микрофон, камера, акселерометр и вибрация.
- Панель навигации: «Назад», «Домой» и «Недавние» работают во всех прошивках.
- ADB по локальной сети и встроенный ADB-терминал.
- Исправлено меню «три точки» в запущенной системе: скриншоты, запись экрана, VNC, SMS, режим полёта, установка APK и другое.
- Кнопку меню можно перемещать в запущенной системе.
- Опция скрытия светового индикатора: в умолчаниях для новых систем и для каждой системы.

### Службы хоста
- Каждый сокет, видимый гостю, теперь объявлен в одном месте (`EndpointRegistry`) и запускается в порядке объявления: у списка служб и их текущего состояния один источник истины. Перезапуск экземпляра больше не тянет за собой объявления прошлой загрузки.
- Рядом с прежними эндпоинтами появился управляющий сокет `aemu_bridge` (bproto2): свойства, питание, буфер обмена и low-memory killer, у каждого свой байт операции. Прежние протоколы (`rild`, `vold`, `dnsproxyd`, `lmkd`) не тронуты.
- Службы хоста выдаются экземпляру из закрытого набора возможностей (`hostCaps` в настройках образа); служба, которую не выдали, отвечает `EPERM`, и на пути диспетчеризации нет никакой рефлексии.
- Режим восстановления больше не оставляет за собой привязанный сокет input после выхода.
- Исправлена раскладка `ab_hello_rep`: в проводе это 76 байт (2 байта выравнивания перед `pid`), а не 74. Теперь это закреплено статическим утверждением C11 — если раскладка снова изменится, сборка упадёт.
- `lmkd` теперь действительно можно выдать: он живёт вне таблицы служб хоста, но внутри набора возможностей, а выдача, не нашедшая цели, раньше тихо пропадала.
- Набор разрешений теперь видно: в настройках есть раздел «Службы хоста» с переключателем на каждое разрешение. Он показывается только для прошивок, чьё ядро экспортирует мост (Android 9 и новее): на старых образах переключатели всё равно ничего не смогли бы.

### Сборка
- Каждый push собирается в GitHub Actions: хостовый тест моста (gcc, `SOCK_SEQPACKET`), самотест байтовой раскладки mock-хоста (Python), сборка `libaemushim.so` под armv7 с проверкой экспорта `ab_call`/`ab_status`/`ab_last_len`, затем JVM-тесты и debug APK.
- Ошибки сборки публикуются как аннотации проверки — логи заданий в публичном репозитории требуют прав администратора.
